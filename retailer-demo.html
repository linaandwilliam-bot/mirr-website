What this page demonstrates

The "Try it on" button under the price is Mirr, rendered inside a store that is not Mirr. A retailer would paste exactly this into their product page — one script tag, one attribute on the price element:

<script src="https://www.trymirr.com/mirr-embed.js" defer></script>

<div class="price" data-mirr-product="forest-compression-tee"
     data-mirr-brand="apex-active" data-mirr-size="M">$54.99</div>

Clicking the button opens the full Mirr try-on — photo upload, fit scores, size recommendation — in an overlay. The shopper never leaves this page. (This demo loads the script from this same site rather than trymirr.com, so it works in local preview too.)
