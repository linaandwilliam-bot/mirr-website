# OUTREACH — templates, the honest ask, and the learning script

Internal, not linked from any page. The material for contacting the first
brands, versioned so it never gets retyped from memory. Everything below
follows the site's locked language: **reduces returns** (never eliminates),
**pre-launch** (never "launched"), fit guidance is **guidance, not a
guarantee**, no AI mentions, no invented statistics, no fake urgency.

## 2. The ask, stated honestly

What Mirr needs from a brand:

- **Product photos** to the stated standard — front-facing, plain light
  background, garment flat, ≥800×1000px (trymirr.com/how-to-measure#photos).
- **Garment dimensions per style** — flat-lay centimetres of the smallest
  stocked size (trymirr.com/how-to-measure#garments). This is real,
  one-time work: a tape measure and a few minutes per style. Never
  undersell it; it is the whole reason the fit scores can be honest.
- Prices, stocked sizes, a short description per product (the form
  requires it), and — before going live — a real product URL per item
  so the BUY button lands somewhere true.

What the brand gets:

- 8% founding commission locked for 12 months (standard 12% after the
  twenty founding spots fill; optional premium placement at 15%).
- No monthly fee, no setup cost, no per-try-on charge, no lock-in
  contract, no exit fee.
- First input on the roadmap and permanent founding recognition.
- From launch: 92% of every sale via Stripe within 2 business days —
  future-tensed because checkout is not live yet, and we say so.

## 3. The learning script (calls, or a reply that opens a conversation)

**The goal of the first twenty conversations is learning, not closing.**
A "no" with a reason is worth more than a polite silence. Ask, then stop
talking:

1. What would have to be true for you to try something like this?
2. Is measuring every style a dealbreaker — honestly? How many styles
   would you actually start with?
3. Does 8% read as fair? What number would? What are you paying other
   channels today?
4. What do returns actually cost you — money, hours, mood — in a typical
   month? What share of them are size and fit?
5. Where do you currently find new customers, and what does that cost?
6. If you tried the demo: what did you expect it to do that it didn't?

Log every answer in [outreach-log.md](outreach-log.md) the same day,
while it's verbatim. Patterns across twenty answers decide the roadmap;
a single answer decides nothing.

## 4. Rules (standing)

- No real brand names in this file — they live in the log only.
- No scraped contact lists; contacts come from public brand sites or
  genuine introductions.
- No invented statistics, testimonials, or social proof — Mirr has zero
  brands today and the templates must never imply otherwise.
- Every claim in a template must be true on the site today, or
  explicitly future-tensed ("from launch", "arrives with launch").
- If site copy and this file ever disagree, the site is wrong or this
  file is — fix one the same day (verify.mjs guards the site's numbers;
  this file is guarded only by re-reading it).
